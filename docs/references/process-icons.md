# Worktree process icons

The `process-*.imageset` assets in `apps/mac/codans/App/Assets.xcassets` use
unmodified SVG artwork from [Simple Icons](https://github.com/simple-icons/simple-icons),
pinned to commit `777807a262bb7384ff406fd4b35fdcd02e9514c3`.

| Asset | Upstream SVG |
| --- | --- |
| `process-nodejs` | `icons/nodedotjs.svg` |
| `process-npm` | `icons/npm.svg` |
| `process-pnpm` | `icons/pnpm.svg` |
| `process-python` | `icons/python.svg` |
| `process-go` | `icons/go.svg` |
| `process-rust` | `icons/rust.svg` |
| `process-docker` | `icons/docker.svg` |
| `process-git` | `icons/git.svg` |

Source files are available in the
[pinned upstream icons directory](https://github.com/simple-icons/simple-icons/tree/777807a262bb7384ff406fd4b35fdcd02e9514c3/icons).
Simple Icons distributes these assets under
[CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/777807a262bb7384ff406fd4b35fdcd02e9514c3/LICENSE.md).
Brand names and trademarks remain with their respective owners.

The image sets preserve vector representation and use template rendering so
the app supplies the foreground color in either appearance. The view controls
their 14-point presentation size; source artwork retains its 24-by-24 view box.
